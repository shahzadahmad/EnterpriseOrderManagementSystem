Phase 2.16 – Repository Interfaces

We'll define repository contracts for each aggregate.

Examples:

IOrderRepository

ICustomerRepository

IProductRepository

IInventoryRepository

IPaymentRepository

Each repository will expose only behaviors that make sense for its aggregate and support asynchronous operations with CancellationToken.
